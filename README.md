# Сравнение моделей рекомендаций top-10

Домашнее задание 1: самостоятельная реализация пяти рекомендательных моделей и их воспроизводимое сравнение.

## Датасет

**Amazon Reviews 2014 — Video Games, 5-core**.

- [Первоисточник и описание полей](https://cseweb.ucsd.edu/~jmcauley/datasets/amazon/links.html).
- Отзывы: строка **Video Games → 5-core (231,780 reviews)** в первой таблице.
- Метаданные: **Per-category files → Video Games → metadata**.
- Общий ключ файлов — `asin`; пользователь — `reviewerID`, оценка — `overall`, время — `unixReviewTime`.

Данные хранятся локально в `data/raw/` и исключены из Git.

## План моделей

1. Item-based collaborative filtering.
2. Базовый iALS.
3. EASE.
4. Factorization Machine с метаданными товаров.
5. iALS с самостоятельно разработанным целевым сигналом.

Обучение, предсказания и формирование рекомендаций реализуются с нуля.

## План эксперимента

- Временное разбиение train/validation/test; конкретные границы определяются при изучении данных.
- Одинаковые пользователи, кандидаты и правила исключения известных товаров для всех моделей.
- Предварительный критерий релевантности: оценка 4–5; основная метрика — NDCG@10, дополнительная — Recall@10.
- Подбор параметров на validation; test используется для финального сравнения.
- Планируемые признаки FM — категории и бренд товара. Метаданные рассматриваются как статические; изменяемые признаки из общего снимка не используются.
- Случайное зерно: `42`. Итоговые настройки, версии и результаты будут записаны в ноутбуке.
