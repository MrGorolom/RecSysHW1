## Метрики

Релевантность у всех методов одинакова: будущая оценка 4–5. NDCG@10 учитывает позицию релевантных объектов; MAP@10 усредняет точность на позициях попаданий с делителем min(10, число релевантных объектов); Recall@10 показывает долю найденных релевантных товаров. Метрики усредняются по пользователям. Основная метрика выбора настроек — NDCG@10. Формулы и реализация: `evaluation.py`.

## Модели

- **ItemKNN:** cosine similarity бинарных историй товаров, усечение соседей и shrinkage. Оценки кандидатов — сумма сходств с известными товарами; отдельного градиентного loss нет.
- **iALS:** взвешенная квадратичная ошибка по всем парам с таргетом 1 для отзыва и 0 для неизвестной пары. Confidence равен 21 и 1 соответственно; L2-регуляризация факторов. Обновления пользователей и товаров решаются поочерёдно через линейные системы.
- **EASE:** квадратичная ошибка восстановления бинарной матрицы взаимодействий + L2; диагональ матрицы весов нулевая. Закрытое решение через Cholesky.
- **FM:** сумма линейных эффектов и попарных скалярных произведений факторов признаков. BCEWithLogitsLoss, Adam; на один отзыв четыре неизвестных train-пары. Признаки — ID пользователя/товара, категории, бренд. Метаданные считаются статическими.
- **Custom iALS:** тот же ALS-loss и confidence; вместо бинарного таргета для известной пары q = 0.5·(rating−3)/2 + 0.5·(rating−mean_user_rating)/4. Пользовательское среднее считается только на обучающей истории. Для неизвестной пары q=0. Низкие оценки могут задавать отрицательное предпочтение.

## Ограничения

- В train-каталоге метаданные сопоставлены для 10093 товаров; категории есть у 10013, бренд — у 149, название — у 253. Большая часть метаданных FM приходится на категории.
- Исходный 5-core отобран по полной истории и смещён к активным пользователям/товарам.
- Новые пользователи и товары исключены; метрики относятся к известному каталогу и аудитории.
- Исторических снимков категорий/брендов нет; их доступность в прошлом — допущение.
- Отсутствие отзыва не означает отрицательное предпочтение. Отзывы не равны покупкам.
- Использованы небольшая сетка и один seed. Разброс результатов не проверялся.
